# Project Facts & Truth Boundary

## Confirmed for this production
- Project name: Mazar Mall.
- 20 physical levels total.
- B2 and B1 underground.
- 18 above-ground floors: 1 through 18.
- Floors 1–2: commercial.
- Floor 3: amenities / lifestyle.
- Floors 4–18: residential.
- Floor 5: second residential floor.
- Residential typical-floor reference is supplied in `assets/references/plans/MAZAR_MALL_TYPICAL_FLOOR.pdf`.

## Architectural reference priority
When references disagree, use this priority:
1. Client-supplied exterior renders.
2. Curated hero references.
3. Typical-floor PDF for plan logic.
4. Furnished unit-plan references for interior visual language.
5. Generated imagery only as derived production material.

## Exterior identity features to preserve
Across every exterior shot:
- Curved / ribbon-like white balconies.
- Dark glazing.
- White architectural frame / portal silhouette.
- Gold-patterned / perforated podium character.
- Dark vertical spine / fins.
- Rooftop / crown identity shown in supplied references.
- Warm integrated facade lighting at dusk/night.
- Mazar Mall brand/signage only where reference-supported.

## Residential floor logic
- Floor 4 = first residential floor.
- Floor 5 = second residential floor.
- Therefore the signature balcony character scene is on Floor 5.

## Amenities
Floor 3 may be portrayed as a conceptual lifestyle / amenities level using the approved project brief. Specific operator brands, exact equipment counts, restaurant brands, or unconfirmed facilities must not be invented.

## Site accuracy
Exact real-world placement requires actual site plates / drone footage / survey imagery.

Before claiming site-accurate compositing, the repo must contain suitable files under:
`assets/site/`

If those assets are missing:
- the film may use a contextual Mazar-e-Sharif urban environment;
- production notes must label it `SITE_MATCH_UNVERIFIED`;
- do not claim exact geographic reconstruction.

## Unit numbering
The supplied plan labels are visual-plan labels, not necessarily official legal unit numbers. Do not manufacture official legal numbering.

## Public-release truth check
Before public publication, a human must approve:
- architectural match;
- site match;
- amenity claims;
- logo usage;
- contact details;
- tagline;
- any text or voiceover making factual claims.
